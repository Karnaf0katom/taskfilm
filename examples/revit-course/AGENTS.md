# Revit course starter

Help a nontechnical Hebrew-speaking teacher produce one short lesson at a time.
Read START-HERE.he.txt and the selected lesson's notes and feedback first.
The Windows setup and real Revit workflow require local acceptance; no autonomous
Revit result has been verified by the kit's preparation on Linux.

The course.py menu coordinates existing owners under owners/: hfrec/OBS records,
humanflow records and replays input, and edit-lane supplies narration and delivery.
Use these owners. Do not create another recorder, editor or TTS client.
The separately installed published Taskfilm package supplies browser-film workflows;
its browser selectors cannot control native Revit.

Never read .env into a prompt, print credentials or commit lesson media/input logs.
Only use owned practice files and the supplied stock narrator. Treat raw replay logs
as private: they include typed text. Revit replay needs the same starting document,
view, UI language, display and scaling. It is not semantic understanding of Revit.
Stop replay when Revit loses focus. Keep old takes and narration revisions.
Do not claim delivery before the teacher opens and approves the actual MP4.
